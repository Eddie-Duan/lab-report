# 物理实验数据处理流程

## 材料优先级：冲突时一律以用户上传/说明的为准

**课程要求和模板每年会变。** 本 skill 自带的模板、`sample/` 里的材料和往年报告全是**往年**的东西，
只能当默认值，不能当规矩。优先级从高到低：

1. **用户本次上传或口头说明的模板、要求、格式**（今年发的 docx / PDF / 截图 / 一句话"今年要写思考题"）
2. 用户自己的旧报告、`sample/` 里的范例与模板
3. 本 skill 自带的 `templates/report.typ`、`experiments.json`、UI 默认选项 —— 只是兜底

具体做法：

- 动手写报告前先确认"今年用的是哪份模板/要求"。用户没提就问一句；提了就以它为准，**不要**再拿
  `sample/` 里的旧模板去覆盖。
- 冲突时（分节名称与顺序、报告头字段、要不要写思考题、字体字号、页数要求）**不要自己挑一个执行**，
  按用户的来；如果用户给的材料本身前后矛盾，把矛盾点指出来问，别默默选。
- 用户临时提的新要求**只对本次有效**，不要写回 skill 当默认值，除非用户明确说"以后都这样"。
- 反过来，用户上传了新版模板时，可以顺手提醒一句"`sample/模板/` 里那份是往年的，要不要保留"——
  但决定权在用户。


下面除"输出到照片同目录"这类明确说明外，路径都相对 `<实验目录>`。

## §0 先把报告头填了（界面给人填，命令行等价）

报告头那堆字段（实验名/姓名/教师/日期/分组座号/地点…）不用手抄进 `.typ`/`.tex`/`.docx`。填一次就行：

- **有人在场 → 开界面**（推荐：字段多，还能一并传记录纸照片和补充文件）
- **纯 agent 场景 → 走命令行**（`make_report.py`，下面有等价命令）

两条路落盘的东西一模一样，包括 `报告参数.json` —— 而**报告头信息的唯一权威就是它**。
界面上填完不必在对话里复述一遍，让 agent 读这个文件即可。

`ui/` 是**可选件**：它只是 `make_report.py` 外面套的一层本地网页（只用标准库、不联网，
由人手动 `python <SKILL>/ui/server.py` 启动）。删掉 `ui/` 不影响 skill 本体；装到别的 agent
（Claude Code / `.agents` / DSH 的 `$DSH_HOME/skills/` 等）时同理：agent 加载的是 SKILL.md、
跑的是 `scripts/`，界面还是由你自己开。所以“要不要界面”与“能不能装进某个 agent”是两件事。

界面：

```bash
python <SKILL>/ui/server.py --root <实验目录>     # 默认 http://127.0.0.1:8722
```

Windows 上还有个更省事的：**双击 `<SKILL>/打开界面.cmd`** —— 它自己找 python、自动用 `--open`
把浏览器打开，实验目录默认用 `..\sample\my_sample`（找不到就用桌面）。想指定目录就把这个 `.cmd`
拖到那个目录上再松手。（那个文件是 **GBK + CRLF** 编码，用编辑器改它时别存成 UTF-8，cmd 会读乱。）

界面里能填：**实验名称**（从 `experiments.json` 的 20 个往年实验名里搜，也能自己写）、
**输出格式**（Typst / LaTeX / Word / Markdown）、学生姓名、教师姓名、实验日期（这三项可留空）、
学号、分班分组及座号、实验地点、同组人员、记录纸照片、补充文件、补充说明。
预习报告、数据记录这两项是**必填**（缺一个就生成不了）—— 它们要当附录排在报告后面，见 §4.3。

生成到 `<实验目录>/<实验>/实验数据/`：

| 产物 | 说明 |
|---|---|
| `实验报告.typ` / `.tex` / `.docx` / `.md` | 报告头已填好、分节留空的骨架 |
| `报告参数.json` | 报告头字段的机器可读版本，**写正文前先读它**，别再从界面抄一遍 |
| `照片/`、`补充文件/` | 上传的文件归档处（同名同内容不会重复堆） |
| `预习报告/`、`数据记录/` | 附录 A / B 的原始文件（PDF/图片都行；生成时已经排进报告末尾） |

生成完的结果区里有一段**「复制以下文本到 DSH 中」**：点一下就复制走，里面已经把 `报告参数.json`、
实验数据目录、照片目录的**绝对路径**写全了，直接粘进 agent 对话里就能开工 —— 不用你自己在对话里
描述格式和路径。（换别的宿主 agent 也这么用，这段话不依赖 DSH。）

不想开界面就用命令行，等价：

```bash
python <SKILL>/scripts/make_report.py --list                    # 看实验名清单
python <SKILL>/scripts/make_report.py --exp 测量金属的杨氏模量 --fmt latex \
    --name 张三 --teacher 李四 --date 2026-09-26 --group 1-04-5 \
    --notes "今年要求写思考题" --file 数据表.csv --photo IMG_1.jpg --root <实验目录>
```

要点：

- **骨架只有报告头 + 分节标题，正文一句都没有。** 正文按 §4.1 的文风自己写；模板里那几句示例
  （`目的之一`、`某量 $x=12.3$`）是占位符，定稿前删干净。
- 报告头版式与分节顺序是**默认值**（Word 那份直接拿官方报告头 docx 当容器，LaTeX 那份取自学长模板的
  导言区与报告头）。当年要求不同就以用户的为准 —— 见开头「材料优先级」。
- 同一实验**换格式不会互相覆盖**（`实验报告.tex` 和 `实验报告.docx` 并存）；同格式重生成要显式勾
  "覆盖已有报告"，免得把写好的正文冲掉。**报告头写错不用重生成** —— 见下面 `--head-only`。
- **预习报告 / 数据记录 是必填项**（界面里缺一个就不给生成）：归档到 `实验数据/预习报告/`、
  `实验数据/数据记录/`，并且**骨架末尾已经排好「附录 A / 附录 B」**把文件跟在报告后面 —— 规则见 §4.3。
- 生成完再进 §1 转录、§3 算数据，最后把结果填进骨架、编译出 PDF（§4.2）。

### 报告头改了怎么办：`--head-only`（正文一个字都不动）

日期填错、分组座号换了、老师名字改了，**别重生成**（那会把已写好的正文冲掉）。只改报告头：

```bash
# 命令行：只给要改的字段，其余沿用上次的 报告参数.json
python <SKILL>/scripts/make_report.py --exp 测量金属的杨氏模量 --root <实验目录> \
    --date 2026-09-27 --group 2-06-7 --head-only

# 界面：勾"只更新报告头"（与"覆盖已有报告"互斥，勾一个自动撤另一个）
```

- 只重写报告头那一块（typst 的 `#let` 值 / LaTeX 的 `\newcommand` 值 / md 的标题+字段表 /
  docx 的大标题+字段表+文档属性），**分节正文、你写的公式图表全留着**。
- 命令行**没给的字段沿用上次的值**，不会被清空；不给 `--fmt` 就沿用上次的格式。
- 报告还不存在时会失败 —— 先用正常模式生成骨架，再来改。
- `--head-only` 与 `--force` 互斥（一个保留正文，一个覆盖正文），界面里那两个勾也互斥。
- 报告头是**按参数重生成**的：你要是手改过报告头的版式（比如在 Word 里调过字段表），改报告头会把
  那几行换回默认版式；正文不受影响。
- **备注块（补充说明／参考文件）不在报告头范围内，不动它。** 要改就写进 `报告参数.json`（agent 读它），
  或重新生成一次（会覆盖正文）。
- 只想看字段值不动文件？直接读 `实验数据/报告参数.json`，不跑任何命令。

## §1 照片 → 原始数据 CSV

### 1.1 预处理：先看清字，再读

整张手写照片直接读会糊。**必须**先切块，否则一定读错数字。

```bash
# 总览：看版面有哪几张表、有没有转 90 度。脚本会打印缩放比，先记住它
python <SKILL>/scripts/prep_photo.py 照片.jpg

# 放大某张表：最稳的是量出总览图上两点的比例(0~1)，跟分辨率、缩放都无关
python <SKILL>/scripts/prep_photo.py 照片.jpg --crop 0.11,0.53,0.59,0.62 --coord rel --zoom 1.6

# 有像素坐标工具时，也可以直接给**总览图**上的像素（别超过总览图自己的尺寸，超了会警告）
python <SKILL>/scripts/prep_photo.py 照片.jpg --crop 330,600,900,700 --coord overview --zoom 1.6

# 真的躺倒时才转正（--rotate 是 PIL 的逆时针角度，90 就是逆时针 90°；只收 90 的倍数）
python <SKILL>/scripts/prep_photo.py 照片.jpg --rotate -90 --split

# 字迹淡/照片发灰时加 --region autolevel（去背景+提对比度）
python <SKILL>/scripts/prep_photo.py 照片.jpg --crop 0.12,0.44,0.90,0.61 --coord rel --zoom 1.2 --region autolevel
```

坐标只有三套，别混：

| `--coord` | 量的地方 | 什么时候用 |
|---|---|---|
| `rel` | 总览图上按比例估（0~1） | **首选**，跟分辨率/缩放无关，最不容易错 |
| `overview` | 总览图像素 | 有像素坐标工具时 |
| `orig` | 原图像素（转正后） | 默认值，手工量原图时才用 |

要点：

- 手机竖拍的照片脚本会**按 EXIF 自动转正**并打印一行说明。"躺倒"多半是 EXIF 没被认，先看有没有那行提示，别急着 `--rotate`。
- 总览是原图长边缩到 `--max-side`（默认 1600）的那张。脚本会打印 `总览 = 原图 x0.533; 在总览上量的坐标 x1.875 才是原图坐标`——这就是为什么直接拿总览坐标当 `orig` 用一定会裁错。
- **脚本的警告不要忽略**。坐标被裁到图外会打印 `警告: 裁切区域 … 超出图片 …`，那说明坐标量错了（或者忘了 `--coord`）。忽略它就会拿到一张"看着正常"的错图，然后读错数字。
- 产物写到照片同目录的 `_prep/`，文件名带裁切区域，不同裁切不会互相覆盖（`…_c330-600-900-700_x1.6_crop.jpg`）。
- `--crop` 和 `--split` 互斥；`--zoom` 只对 `--crop` 生效，用错会直接报错/警告。

**裁切是唯一可靠的办法**——一眼扫过去读宏观表，数字一律靠裁切图逐个确认。

### 1.2 读的纪律

- **认不清就问用户，不要猜。** 手写数字、涂改、单位、批注都问。问的时候把证据一起给（"我读到 X，但 Y 处矛盾"），用户能秒答。
- **涂改以改后为准**，划掉的原值记下来但不用。
- **批注决定单位**。记录纸表头印的单位经常是错的（印 `/mm` 实际写的是 cm），页边批注（"(cm)"、"需乘0.01"、"(+100)"、"千分尺零点 0.011mm 未减"）才是真的。表头印的、表里写的、页边注的三者不一致时，**问**。
- 仪器会转圈。鼓轮读数越过 100 要加回 100，不然会出现负位移。
- 同一个符号在不同实验里含义不同（`d` 既可能是直径也可能是刀口间距），按节读，别跨节套。

### 1.3 写 CSV

```bash
# 检查编码。--check 是 dry-run，一个字都不改，放前放后都行；需要转换时退出码 1
python <SKILL>/scripts/to_utf8.py --check 1.杨氏模量/实验数据/
python <SKILL>/scripts/to_utf8.py 1.杨氏模量/实验数据/          # 就地转 UTF-8 BOM，原文件备份 .gbk.bak
python <SKILL>/scripts/to_utf8.py --clean 1.杨氏模量/实验数据/   # 确认无误后删备份(按后缀全盘找, 改名后的孤儿也删得到)
```

转换时会打印"转出来长这样: …"。**瞄一眼那一行**。碰上"按 UTF-8 和按 GBK 都读得通"的字节，
脚本**不猜**：它会把两种读法都打出来并拒绝转换（退出码 1），你确认哪个对，再加
`--assume gbk` 或 `--assume utf8` 重跑。

用 `csv_tables.py` 写，它自动加 BOM + CRLF：

```python
import sys; sys.path.insert(0, r'<SKILL>/scripts')   # 换成实际路径
import csv_tables as ct

ct.write('1.杨氏模量/实验数据/2_霍尔法.csv',
  [('横梁的几何尺寸',
    [['测量次数', '1', '2', '3'],
     ['长度d/cm', '23.60', '23.55', '23.57']]),
   ('读数显微镜示数',
    [['序号', '1', '2'],
     ['Zi', '01.9', '16.5']])],
  comments=['霍尔法 原始读数 —— 照抄记录纸, 未换算',
            '长度d 单位 cm; 厚度a 需减千分尺零点 0.011'])
```

```bash
# 检查写完的 CSV 能不能正确解析（有问题退出码 1）
python <SKILL>/scripts/csv_tables.py 1.杨氏模量/实验数据/2_霍尔法.csv
```

**CSV 里只存记录纸上的手写原值，不做任何单位换算。** 零点修正、单位换算全部留给 §3 的脚本。
这条是整个流程的核心纪律：一旦在数据文件里预先换算，就会出现"同一个量在两个文件里单位不同"，
而且事后无法从文件本身看出来（实际踩过：宽度 22.16 mm 被写成 0.2216）。

配套的三条硬规矩（脚本会直接报错，不是建议）：

- **格子里只写字符串**，写 `'23.60'` 不写 `23.60`。传 float 会被拒绝：`23.60` 丢有效位变 `23.6`，
  `0.1+0.2` 会写出 `0.30000000000000004`。
- **不填 0**。空格子留空表示记录纸上没有，读出来是 `None`；填 0 会被当成一次真实读数。
- **别把批注写进数据格子**。`row()/col()` 遇到"有值但读不成数字"的格子会直接报错——那是读错/写错
  的值，不能和"记录纸上没有"混为一谈。

分段标记 `# ---- 名称 ----` 后面第一行是表头，其余是数据行。同名分段会报错（拒绝静默覆盖），
某行比表头列少会带行号警告并按空格子补齐（否则 `zip` 会静默截断，逐差法就少算几组）。

## §2 核对：确认前不计算

录完后**先交核对清单，不要直接算**。用户会逐项对，尤其是：

- 每个标了"我把握不足"的值
- 涂改过的格子
- 单位/批注的判断

同时产出一份放大图目录（把 §1.1 的裁切图按表名重命名归档），用户核对时比翻原照片快得多。
确认后把结论写回记录（该实验目录的 README 或 CSV 表头注释），再进 §3。

## §3 处理脚本

一个实验一个 `处理.py`，放在 `<实验目录>/<实验>/实验数据/`。结构固定：

```python
# 1. 顶部「约定」区：所有修正和仪器误差集中在这里，每条注明出处
L_MM = 778.0;  E_RULER = 1.0        # 卷尺分度值 1mm
D_CORR = -0.005                     # 页边批注 "-0.005"
Z_PLUS = 100.0                      # 鼓轮过一圈, 旁注 "(+100)"

# 2. 读 CSV（用 csv_tables），只读原始值
# 3. 修正 + 计算；把每张中间表和每个公式都打印出来
# 4. 出图存 fig1/fig2/fig3*.png
# 5. 报告同时 print 到屏幕 和 写 处理结果.md
```

要点：

- **读原始数据一律走 `csv_tables.row()/col()`**：格子空着给 `None`，格子有值但读不成数字会直接报错。
  别自己 `open()` + `float()`——那等于把 §1 的核对白做一遍，错字会静默变成 `None`。
  标签有歧义（`长度d` 同时命中 `长度d/cm` 和 `长度d/mm`）也会报错，写全标签。
- **不确定度把两种取法都打出来**：`u_B = e/√3` 和 `u_B = e`。指导书一般没规定 A/B 类取法，
  做成顶部开关 `DIVISOR_B`，两种结果的最终值都打印，用户按老师要求选。
- **仪器误差要问用户**，指导书经常没写。按行标注"按常用仪器取值，待确认"，别默默假设。
- 逐差法配对时**用实际差值**，不要假设等间隔——实测质量常不是严格等差（如 19.9/40.0/60.5…）。
- 拟合求极值（如外推法的曲线最低点）时，**报告模型间的差异**：二次拟合顶点 vs 两支直线交点
  给出的结果可能差 1 Hz 量级，这比仪器不确定度大得多。
- 跑完把脚本输出连同一句话结论给用户（`print` 中文没有编码问题，脚本在被捕获时自动切 UTF-8）。

### 3.1 作图与制表要素（照课程《数据表、曲线图要素示意》对一遍）

课程自己发的那份示意图在 `sample/参考/数据表曲线图要素/`（数据表一张、曲线图一张，本机有就直接看一眼）。
要素就这几条：

**数据表**（表题在**表格上方**）

| 要素 | 要求 |
|---|---|
| 表头 | 写清**物理量**，带符号：`测量次数 n`、`测量周期 T` |
| 单位 | **单独一列**、括起来：`(次)`、`(s)`。不要把单位塞进数据格，也不要每格重复写 |
| 数据 | 同一列小数位/有效数字一致，右对齐好读 |
| 表题 | `表一：摆长为 70cm 时不同测量次数 n 测得的周期 T` —— 编号 + 条件 + 量，在表**上方** |

**曲线图**

| 要素 | 要求 |
|---|---|
| 坐标轴 | 轴标写**物理量 + 符号 + 单位**：`输出电压 U(V)`、`加载重物质量 m(g)` |
| 坐标标度 | 取值范围和刻度选得便于读数（别让点挤成一团） |
| 图例 | 多组数据/多种方法必须标（`半桥时`、`全桥时`，点型要区分得开） |
| 数据点 + 拟合线 | **实测数据点是点**（带符号），**拟合结果是线**，两者都画出来 |
| 拟合表达式 | **直接写在图上**：`y = 0.005x   R² = 1`（每个拟合都写，带 R²） |
| 图题 | 写在图**下方**：`输出电压随加载重物的变化关系` |

- 当年要求不同（列数、是否要求 R²、图题位置）**以用户/指导书为准** —— 先把上面这些排好，再按用户说的调。

## §4 报告

**硬指标：全报告 ≤10 页（含附录 A/B）。** 超了按这个顺序压，别靠缩字号糊弄：

1. **附录**：一张图别占一页。生成器已把附录图限高到 44% 页高（LaTeX `height=0.44\textheight,keepaspectratio`、
   Typst `height: 44%`、docx 按 5.9×4.4 英寸框缩放），正常一页两张；PDF 附录用 `\includepdf`，整份插进来。
2. **图**：同类截图/曲线合成一张多子图（`subcaption` 并排、或 Typst 里 `#grid`），单图宽 ≤0.8\linewidth。
3. **公式**：中间推导并成一行（`$a=b=c$`），同一个式子全文只排一次。
4. **文字**：按 §4.1 删复述与铺垫；**一节不超过 1 页**。
5. 前面都试过才动页边距 / `\vspace` / `leading`。

页数还超，说明内容真的多：砍与结论无关的现象描述和冗余数据表，**别牺牲数据本身的准确性**。
报告页数跟分数无关（课程要求里明写着"成绩与篇幅无关"）。

### 4.1 文风（用户明确的底线）

- **删掉所有中间代入算式**。"没人要看你列算式算平均值"——`d̄=(0.185+…)/6=0.18517` 这种
  只留结果 `d̄ = 0.18517 mm`。公式就写 `Y = 4MgL/(πd²ΔL) = 2.63×10¹¹`，中间那串数字删掉。
- **不要为了写长而写**。目的写三条就行，别凑第四条套话。
- **括号里不放填充**。"（需要注意的是…）""（顺便一提…）"一律删。
- **和标准值的偏差别当成"待排查问题"**。指导书自己都写了标准值仅供参考。数据质量看
  ① 拟合 R² ② 不同处理方法之间是否自洽（逐差法 vs 作图法差多少），不是看离标准值多近。
- **不复述**：表格里有的数字正文不要再列一遍；同一句物理解释全文只讲一次；
  不要另设"数据质量"章节把前面的数字抄一遍。
- 正文顺序：目的 → 原理 → 仪器 → 数据 → 处理 → 结果。

### 4.3 附录 A / B：预习报告与数据记录

课程、老师常要求把**预习报告**和**数据记录**附在报告后面。§0 上传时它们就被归档到
`实验数据/预习报告/`、`实验数据/数据记录/`，**而且骨架末尾已经把两节附录排好了** ——
写正文时不用管这两节，但定稿前必须检查一遍：

- 骨架末尾那两节**别删**（LaTeX 里是 `\section*{附录 A\quad 预习报告}` 配 `\includepdf`/`\includegraphics`
  摆在 `\end{document}` 之前）；也别把正文写到附录后面去。
- **LaTeX**：图片排成 `\includegraphics[width=\linewidth,height=0.44\textheight,keepaspectratio]{数据记录/xxx.jpg}`
  （**限高是关键**：不限高的话手机竖拍图一张就占满一页，附录能多出两三页），图片之间不加 `\clearpage`；
  整段附录只在开头有一个 `\clearpage`。PDF 排成 `\includepdf[pages=-,fitpaper=true]{预习报告/xxx.pdf}`；
  导言区用 `\IfFileExists{pdfpages.sty}` 兜着 —— 装了就真嵌，没装就在原位画一个提示框，**不会编译失败**。
- **Typst**：图片能嵌（`#image(..., height: 44%)`）；**PDF 嵌不进去**，骨架里只留了注释 —— 碰到 PDF
  就告诉用户改用 LaTeX 出，或先用 PDF 工具把两份合并。
- **Word**：图片**真的内嵌进 docx**（生成时写 `word/media/` + 关系 + Content_Types，一页两张）；
  PDF 塞不进去，那一行会写成"当附件单独交，或用 LaTeX 出报告"。**Markdown**：用 `![](路径)` 引用，
  PDF 用链接。
- 命令行/agent 路径没有"必填"限制：用 `--prelab <文件>` `--record <文件>` 传（可重复）。
  要是当时还没拿到，就等拿到再生成骨架；已经生成了的，定稿前手工把附录那几行补上去
  （LaTeX 就三行：`\clearpage` + `\section*{附录 A\quad 预习报告}` + `\includepdf[pages=-]{预习报告/xxx.pdf}`）。
- 当年要求不同（附录顺序、要不要附录、单独交）**以用户的为准** —— 见开头「材料优先级」。
- 原版模板里这一节写作 `\section{实验原始数据记录表}` + `见后附图` + `\includepdf[pages={1-4}]{record.pdf}`
  （课程原始写法，见 `templates/latex/原版参考.tex`）。我们生成的是等价物（`pages=-` = 全插）；
  用户要求贴课程写法时，把生成的那行 `\section*{附录 B\quad 数据记录}` 改成 `\section{实验原始数据记录表}` 即可。

Typst 模板里已经有：三线表 `#bt()`、单位 `#u("mm")`、表格居中、中文字体、公式编号、报告头变量。
图放在报告同目录，把注释掉的那段改成 `#figure(image("fig1.png", width: 55%), caption: [...])`。

LaTeX 模板的导言区**只留了本机确实装着的包**（`xelatex` 验证过能编出 1 页 PDF）。原始那份导言区更全，
但里面 `circuitikz`、`pdfpages`、`algorithm`、`mathtools`、`siunitx`、`mdframed`、`wrapfig`、`fontsize`、
`adjustbox`、`breqn`、`mathrsfs`、`amsthm` 这些本机没装；要用就加回去，MiKTeX 会自动联网装
（`mpm --install=circuitikz` 也行）。`subfigure` 已废弃，已换成 `subcaption`。

排版压不下页数时按 §4 开头那五条顺序收（附录 → 图 → 公式 → 文字 → 页边距），
结果表还可以加 `#block(breakable: false, ...)` 防跨页。

## 踩过的坑

- **`bar(x)` 在 Typst 里是竖线符号**，不是上划线。均值必须写 `overline(x)`，
  否则渲染成 `|x|`。
- **Typst 表格默认齐左**，加 `#show table: it => align(center, it)` 才居中。
- **Typst 表格单元格里写 `"字符串"` 不会当标记解析**，`$公式$` 会原样印出来。
  必须写内容块：`([序号 $i$], [$M\/"g"$])`。
- **Typst 的 `%` 不是注释**（注释是 `//` 和 `/* */`），所以 `6.72%` 可以直接写。
- **Typst 的 `image()` 找不到文件就直接编译失败**，所以模板里的 figure 段默认注释着。
- **PDF 文字提取会打乱分数**：指导书里 `E = d³Mg/(4a³bΔZ)` 的 4 在分母，
  文字提取会把它提到分子位置。**公式一律渲染原页图片核对**，别信提取的文本。
- **照片"躺倒"先怀疑 EXIF**：手机竖拍的照片像素是横的、靠 EXIF 标记转正，相册里看着是正的。
  `prep_photo.py` 会 `exif_transpose` 自动转正并打印一行说明；没那行提示才是真躺倒，再 `--rotate`。
- **裁切坐标有三套单位**（原图 / 总览图 / 0~1 比例），这是最容易读错数字的一步。
  默认按原图算，在总览上量的一定要加 `--coord overview`，否则裁出来的图"看着正常"但是错的。
- **原始数据 CSV 只收字符串**：`write()` 拒绝 float（`23.60` 会变 `23.6`，`0.1+0.2` 会写成
  `0.30000000000000004`）；读的时候"有值但读不成数字"会直接报错，不再静默变 `None`。
- 长图路径里带中文时，桌面端的文件面板打不开，让用户自己开。
- Python 是 Windows 版，`/tmp/...` 这种路径它不认，脚本里用相对路径或完整 Windows 路径。
- **别用 `python -c "…中文…"`**：GBK 控制台下命令行参数会把中文源码本身弄坏（实测 SyntaxError）。
  一律写成 `.py` 文件再跑（文件是 UTF-8，Python 按 UTF-8 读源码，稳）。

## 排查

| 现象 | 原因 / 处理 |
|---|---|
| 打开 CSV 的中文是乱码 | 文件是 GBK。跑 `to_utf8.py` |
| `to_utf8.py` 打印"两种读法都通" | 这段字节 UTF-8 / GBK 都读得通。看它打出的两行预览挑对的，加 `--assume gbk` 或 `--assume utf8` |
| `to_utf8.py` 报"已有备份，保留不动" | 正常：最早那份 `.gbk.bak` 不会被后来的覆盖，要还原就用它 |
| 脚本**屏幕输出**的中文是 `���` | 输出被管道/agent 捕获时脚本会自己切 UTF-8；还乱就加 `PYTHONUTF8=1` |
| 打开 CSV 第一列多了个 `\ufeff序号` | 读的时候用了 `utf-8` 而不是 `utf-8-sig` |
| 读 CSV 报"有一行不在分段之内" | 缺 `# ---- 名称 ----` 标记 |
| 读 CSV 报"分段名重复" | 两个同名 `# ---- X ----`，改名（以前是静默丢掉前一段） |
| 读 CSV 报"这行 N 列, 表头只有 M 列" | 值里有逗号。把逗号去掉，或拆成两段 |
| 警告"只有 N 列, 表头 M 列, 末尾按空格子补齐" | 行尾少写了格子。补齐不会报错，但 `zip` 会静默少几组，尽快补 |
| 读 CSV 报"格子 '…' 读不成数字" | 数据格子里混了批注/错字，或那一位本来就读错了。回去看裁切图 |
| 警告"没有 BOM" | 文件被 Excel 另存过了，重跑 `to_utf8.py`（纯 ASCII 文件不会警告） |
| 警告"裁切区域超出图片" | 坐标量错了，或忘了 `--coord overview`。**别忽略**，裁错了就会读错数字 |
| 报"裁切区域是空的/完全在图片外" | `--crop` 的四个数是 x0,y0,x1,y1，确认没写反 |
| Typst 编译报找不到 `fig1.png` | 图还没出就取消注释了 figure 段；先出图，或再注释回去 |
| Typst 编译报字体缺失 | 改 `.typ` 里 `#set text(font: ...)` 那行的字体名；`typst fonts` 看有哪些中文字体 |
| LaTeX 编译报缺包（如 `circuitikz.sty not found`） | 导言区只留了本机装着的包；要用别的先 `mpm --install=<包>`，或让 MiKTeX 联网自动装 |
| 界面里选了 Typst 却编译不了 | 本机没装 typst（界面不标了，用 `typst --version` 确认）；装 typst，或改选 LaTeX / Word |
| 报告页尾大片空白 | 图太大被挤到下一页。缩图宽，或给表格加 `#block(breakable: false)` |
| 生成的报告头字段是空的 | 正常：留空的字段在报告里画成下划线空格，想填就在界面里补上再生成 |
| 改报告头把正文冲掉了 | 下次用 `--head-only`（或界面勾"只更新报告头"）：只重写报告头，正文一个字都不动 |
| `--head-only` 报"还没有/没找到"报告 | 正常：它不新建文件。先用正常模式生成骨架，或确认 `--root` / `--dir-name` 指对了目录 |
| 拿不准脚本有没有改坏数据 | 跑 `python <SKILL>/scripts/selftest.py`，它把上面这些边界情况全测一遍 |
